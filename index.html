Top Movies and Series List

Automatically updated daily from TMDb weekly trending lists

📋 Simple List (JSON) 📊 Detailed List (JSON)

📊 About This Data

This list combines TMDb's weekly trending movies and TV shows, updated automatically every day at 6:15 AM UTC.

This product uses the TMDB API but is not endorsed or certified by TMDB. The Movie Database (TMDB)

🔗 Direct API Access

You can fetch the data directly via HTTP requests:

# Get simple list
curl https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/top-list.json
# Get detailed list
curl https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/top-list-detailed.json

📝 Data Format

Simple format contains just titles:

[
  {"title": "Superman"},
  {"title": "Squid Game"}
]

Detailed format includes metadata:

{
  "last_updated": "2025-01-08T15:30:00.000Z",
  "total_items": 50,
  "items": [...]
}
